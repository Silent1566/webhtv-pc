# 可跳过片段：进度条、菜单与自定义颜色

## 使用方式

- 播放器在原进度条对应片段区间内直接换为分类颜色，与缓存/已播共用同一条轨道和高度，不再显示上方色带；悬停可查看类型和起止时间，关闭缩略图也可读。
- 右键 **跳过片段** 可选择跳过模式、七类类型开关或立即跳过；原片头/片尾手动标记和快捷键保留。
- **跳过片段 → 片段颜色…** 进入设置，每类可选预设色或输入 `#RRGGBB`，支持整体恢复默认；保存后返回播放器生效，重启保留。
- 七类是回顾、片头、片尾、预告、彩蛋、广告、休息。标记依赖当前视频实际获取的远端标定或现有手动标记，不是对任意广告自动识别的承诺；没有区间时不虚构标记，相应立即跳过项置灰。
- 右键 **跳过片段 → 显示片段高亮** 与设置页同名开关可关闭颜色，并持久化；关闭只恢复原已播/缓存轨道，不影响识别、悬停或自动跳过，也不清空自定义颜色。颜色区间外保留原已播/缓冲显示，滑块与拖动语义不变。
- **跳过片尾到文件末尾按「本集看完」处理**：不再重开当前流到总长等 EOF，直接按既有自动连播/循环/季边界/队列策略前进，并把这集的历史与季度进度记为完成（不会被定时保存或退出覆回片尾起点）。用户回拖或重新播放即解除。有限片尾段后面还有内容时只跳段末，不算整集结束。开启「本集结束后关闭」时优先停止，不连播。
- **标记不等于已跳过**：色带证明有可用时间区间；实际自动跳转还要满足模式、类型、有效时长、续播已落定与未处理过该段。视频和必要续播就绪后即可判定，不应等待字幕、弹幕或其他辅助装配结束。已处理片段不会因用户回拖反复跳；直播不自动跳段。
- 设置分类「播放」中的直接入口与播放参数内入口均使用 **跳过片段**，避免只改明细页而留下旧名称。

## 审阅中已处理的风险

- 低对比默认/自定义颜色：保留RGB，增加可读轮廓；像素测试覆盖暗亮主题与端点不越界。
- 设置返回旧偏好快照：专用颜色入口和原「设置 → 完整设置页…」入口共用返回同步；真实逐层导航、保存、返回、模式修改与磁盘读回覆盖，不丢新颜色。
- 暂停时远端标定到达不刷新：在挂载守卫后重建；测试不推进时钟/位置也立即得到区间。
- 多广告/休息跳回首段：优先当前命中，否则后续未结束段；已结束不倒退。
