# 自动模式已标记却不跳过：复现与修复

## 用户症状与确认事实

设置为自动模式、七类全选，播放器已绘出片头色带，但在片头内（用户截图约00:11）仍播放。用户日志显示远端标定先到、随后引擎给出有效时长，没有自动跳段执行记录。安全过滤确认当前偏好为 `skipMode=auto`、`skipKinds=127`，不是未开启开关。

日志本身不能确定实际那次卡住的是哪项辅助服务；以下根因来自可重复的真实 PlayerPage 测试，不把推测当作外部实况。

## 已证实根因

原 `_load()` 在视频打开成功后仍依次等待播放增强/LUT、默认字幕、karaoke、弹幕装配，最后才开启 `_skipArmed`。视频和片头标定可用时，任一辅助 Future 未完成都会让片头内自然位置事件在 `_maybeAutoSkip()` 入口直接返回，尚未发出 seek。进度条有颜色只证明识别到区间，不证明自动动作已下发。

失败回路：真实 PlayerPage，auto/all，playing=true、位置11s、Slider包含intro，真实弹幕或字幕装配已收到请求但gate未完成；期望实际传输收到一次seek30s，修复前为空。

## 最小修复

- 视频打开并完成必要续播恢复后，即允许自动跳过；辅助步骤仍按原顺序await，但不再阻塞自动跳段。
- 菜单切换到自动、或打开类型按原规则升为自动后，立即判定当前位置，不必等待下一次位置事件。
- 保留跨buffer重开定位通道：目标超已知buffer时记录新的 `Media.start`，不退回裸seek。
- 保留已处理段、续播越过片头、回拖与单集循环保护；直播不自动跳段，关闭/先询问模式不被改成自动。
- 字幕await返回后先检查mounted/媒体代际，避免旧加载在自动重开后继续重置新媒体karaoke轨道；回归通过公开面板的生产session观察真实评分轨身份。
- 设置分类「播放」的遗漏入口文案改为「跳过片段」，真实点击导航覆盖；不是只改明细页标题。

## 验证证据

- `test/player_skip_menu_test.dart`：自动模式实际seek、标定/时长先后、字幕/弹幕阻塞、即时模式/类型变更、跨buffer open.start、off/confirm、回拖、续播、单集循环、直播、旧字幕完成不能清除新karaoke评分轨。
- 生命周期测试使用真实完成条件和15秒真实时间上限，不依赖固定flush轮数；缺少单行代际守卫时，最终测试仍能复现新评分轨变null，恢复后通过。
- 最终Lead独立门禁：auto/续播/队列/菜单199项、设置39项、历史/拖动/生命周期70项、字幕/弹幕18项，合计326项通过；全包 `dart analyze --fatal-infos .` 无问题，`git diff --check` 通过。
- 媒体IO使用隔离fixture，远端标定输入重放给生产provider/SkipPlan，实际观察生产页面下发的seek/open.start与真实karaoke状态；不声称已验证用户那条外部影视的真解码结果。

## 范围

不修改用户配置/数据库，不更改协议、存储、默认模式或片段类型；长日志中其它配置刷新、桥接、图片请求等不属于本次修复。生产改动集中在 `player_page.dart` 加载/跳过事件链与 `diagnostics_pages.dart` 一行入口标题。
