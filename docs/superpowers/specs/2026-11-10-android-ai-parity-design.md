## 架构与边界
复用现有四协议 AiCompletionClient，增强配置与协议兼容；消费者保持独立。AI 输出是外部不可信数据：类型校验、范围校验、正则安全检查通过后才能应用，广告与分组有预览确认。共享设置文件走统一写合同；新业务缓存放配置目录下任务专属 JSON 或既有专属数据库表，不让不同消费者独立覆盖 settings.json。

原生音频识别/音高推理需要真实 Windows 引擎、模型和播放器音频采集；可替换适配器仅为测试注入，生产路径不许用假结果或不可用占位。音频流携带媒体会话与时间戳，换集/seek/关闭取消过期任务。模型下载展示进度，校验失败不激活模型；不复制 Android JNI 到 Windows。阅读器与语音搜索补必要业务入口，维持 Spider 隔离与现有网络出口约束。

UI 保持 NavigationRail/AppBar、现有 Material 字体度量与 AppSemanticColors；新增控制不改变视频区域尺寸，不移动测试精确定位的字幕轨/弹幕按钮。不改变旧配置和默认关闭状态下的既有播放行为。

## 已发现且必须路由的风险
1. 四类 AI 辅助目前仅粘贴预览，不代表实际业务消费：由业务域与统一集成任务补齐。
2. EXPLICIT_MAPPING 当前仅预览：由季集域补解析、应用与持久化。
3. 画像旧响应跨范围显示：由推荐画像域按输入指纹缓存并丢弃过期结果。
4. AI 配置独立异步读改写可能覆盖其他 settings 分段：由公共底座任务接入共享写合同并做回归。
5. 日志用户输入无显式脱敏：公共诊断消费者发送前脱敏。
6. 五套提示词缺失：公共底座移植版本、custom 标志与旧版升级，备份同步保真。
7. Android ARM JNI 与 Windows 不兼容、模型许可未核实：原生域采用官方资源、记录版本/许可/哈希；不伪称模型运行验证通过。

## 任务与验收归属
A 公共底座：配置/五套提示词/四协议/SSE整包兼容/共享持久化/AI设置页。
B 内容智能：推荐与负反馈、结构化画像、真实片名学习与缓存、分组规则、AI广告规则、自动日志诊断；独立服务和新页面，不改共享接线。
C 季集与元数据：四模式完整应用、逐集显式映射持久化及业务解析，必要元数据回退。
D 原生音频：sherpa识别/VAD、字幕翻译、模型管理、音频采集、BasicPitch音高评分；依赖与Windows打包由此单一任务所有。
E 附属语音：语音搜索、阅读器与Edge Neural TTS；独立页面/服务，先交付接口再统一接线。
F 统一集成：AppState、导航/详情/搜索/设置/播放器/代理接线、备份同步数据保真与用户可见完整链。
A、D、E 可并行；B、C 在 A 接口明确后并行；F 在服务合同稳定后统一接线。每简报首次加至多两次重派，共三次运行；独立复审不能由自检替代。
