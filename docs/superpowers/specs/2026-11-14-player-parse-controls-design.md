# 播放器解析选择修正

## 确认记录

- 已定：用户在 Q1-parser-scope 选择“按上述范围修正”；解析选择从选集弹窗移至播放器控制区。
- 已定：仅本次播放实际走可切换的配置解析器时出现；直链、网盘返回直链、本地文件、直播不出现。
- 假定：固定的 `json:` / `parse:<名称>` 指令不提供无法生效的手动切换；保留既有解析优先级与前缀语义。
- 排除：不增加全局解析设置，不改变分支名或上游，不提交、不推送。

## 依据

- Android `app/src/mobile/res/layout/view_control_vod.xml:258`：解析条在播放器控制区。
- Android `app/src/mobile/java/com/fongmi/android/tv/ui/activity/VideoActivity.java:3436-3447`：可见性由本次播放结果决定。
- PC `apps/desktop-flutter/lib/ui/player_page.dart:4723-4729`：目前直接读取全局配置，无播放路径判断。
- `DESIGN.md:391-410`：播放器职责不重复、浮层不改变视频尺寸、恒定暗色。

## 完成标准

1. 选集弹窗仅含线路、区间、剧集，不再包含解析器。
2. 播放器控制区有独立且标识清楚的解析条，只在当前请求带有多个可切换解析选项时显示。
3. 解析状态由服务结果显式传递，通过代理、首次播放、换集、切线路、切画质、历史续播与目录播放不丢失；新直链结果清除旧解析选项。
4. 跨配置历史沿用原配置的解析器，不读取当前全局配置来展示原来源解析选项。
5. 切换重新解析当前集，只在本次播放生效；超级解析和手动解析选择状态准确，无无效入口。
6. 新增回归测试先失败后通过；已有选集与播放测试不回退；同场景、尺寸、主题的 Before/After 光栅截图可比较。

## 视觉约束

沿用现有星等琥珀、表面阶梯、ChoiceChip、无阴影和横向鼠标拖动；不修改视频布局与现有字幕、弹幕、更多菜单的入口。
