# ADR 0014 播放器内的弹幕地址列表与页签设置

状态：接受（已落地，经只读评审 + Lead 独立验收）。日期：2026-11-23。

## 背景

用户最初要求播放器弹幕设置参考安卓版、能看到有哪些轨道/选项，随后澄清：
「我说的是弹幕地址显示……你理解错了，当然你现在的改动也还不错」。
原先把诉求解释为行数、区域等显示参数并不准确。用户选择保留新增的设置弹层，
在其中增加可切换地址的「弹幕源」页签。

安卓版的地址入口是 `DanmakuDialog`：从播放器取得 `getDanmakus()`，
列出候选名称并高亮选中项；显示样式另由 `DanmakuSettingDialog` 管理。
PC 已有本集 `PlaybackRequest.danmaku` 与当前点播地址，但此前播放器设置
没有将这份地址列表展示出来，只有开关、搜索与整页入口。

## 决策

1. 两个原入口（右键「弹幕 → 弹幕设置…」、顶栏「更多 → 弹幕设置」）共用
   `_openDanmakuQuickSettings()`；不增加重复的顶栏按钮。
2. 保留「显示 / 时间 / 轨道」及现有 12 个显示项，新增「弹幕源」第四页签。
   顶部当前弹幕摘要可点击直达地址页签；地址数量按本集候选计数。
3. **资源地址与搜索接口分开**：本集候选列表列的是可加载的弹幕资源地址，
   弹幕库一行显示配置解析出的接口地址。接口增删改仍由整页管理。
4. 本集地址列表展示名称、地址、当前项与载入条数；直播源有独立标记。
   地址格式化不得丢掉影响区分的端口与 query。来自搜索或匹配记忆的当前地址
   即使不在本集列表中也要展示，不能让当前来源无处可查。
5. 点非当前行切源，正在加载时给出反馈；失败明确显示错误、不阻断视频。
   当前选择、加载成功、直播连接状态不能混为一谈。点当前项不重复请求。
   点播与直播切换须清理旧类型的数据与会话，重开弹层仍以播放器真实状态为准。
6. 搜索入口复用已有对话框；空状态显示「本集没有弹幕地址」并提供搜索与
   弹幕库设置入口。弹层返回下一步动作，显示项已经即时应用，不重复提交。

## 语义口径（评审后补齐）

- **本集资源地址 · 展示**：`scheme://host:port/path?query#fragment` 进 64 字符中间
  省略；端口与 query 必须保留（同一台机器的 :9321 / :9322 是两台中转），并给每条
  地址与顶部摘要包 `Tooltip`，悬停读得到完整 URL。
- **「当前」= 用户选中的那条源**，与「是否已连接/已载入」分开表达：直播行显示
  「当前在用 · 已连接/连接中/重连中」，握手失败显示错误色「连接失败：…」且不给
  对勾；点播行成功且条数 > 0 才附「已载入 N 条」。直播不显示条数（15s 滑动窗口
  的条数没有稳定语义）。
- **弹层持有的是打开时刻的快照**：`_openDanmakuQuickSettings` 记下
  `_mediaGeneration`，选源入口先比对代次，不一致直接拒绝并提示重开——追剧自动
  连播时弹层还开着，也不会把上一集的地址装进新一集。
- **切换要清另一路**：进直播先清点播数组与地址，进点播先销毁直播会话；
  `_configureDanmaku` 开头统一销毁旧直播会话，避免跨集残留让「当前」指向旧 ws 地址。
- **弹幕库那一行是只读的接口信息**：显示解析出的第一条地址与总数（「共 N 条」），
  点击进整页；增删改不在弹层里。

## 明确未做（接受的已知限制）

| 未做项 | 理由 |
|---|---|
| 同一集里快速连点两条源，后完成的覆盖先完成的 | 需要跨弹层生命周期的请求序号；本轮只保证「切集快照失效即拒绝」，并发覆盖留给后续 |
| 切源失败后保留原弹幕 | `_loadDanmakuSource` 既有语义是失败即清空；改它会动播放行为，不在本轮 |
| 把「成功但 0 条」判成成功 | 只把文案改成「该源没有弹幕」，判定逻辑不变 |
| 直播切换前固定等 100ms 让事件落地 | 让「连接中」不被当成成功的最小代价；不是理想方案 |

## 取舍与边界

- 复用现有弹层而非新增独立弹幕列表窗口：保持用户已认可的改善，避免新增
  一个重复设置入口。参考安卓的来源列表与当前项语义，不照搬移动端所有动作。
- 源接口管理留在整页，弹层只负责当前播放地址的查看与选择，不复制源编辑器。
- 不扩展 `DanmakuStyle`、协议与存储字段；阴影/投影、颜色模式、间距等
  安卓专有显示选项不属于本轮地址显示需求。
- 弹层沿用应用暗色主题与 BottomSheet，宽度上限 720、高度上限 620 或窗口 90%；
  高度受限时内部滚动。新的地址页签没有可靠的改前截图，采用改后取证。

## 完成判据

地址可辨认且当前状态真实；异步选源不会污染新媒体；直播与点播不会残留；
显示项、搜索和完整设置页入口不回归。由行为测试、播放器接线测试、独立分析
及地址/空状态截图共同验收，不把子代理通知当成通过。
