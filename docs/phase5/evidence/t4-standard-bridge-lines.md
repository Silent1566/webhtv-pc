# 桥接线路标准化验证

日期：2026-10-11。

## 目标

桥接站点的 folder 资源不再先显示“选择资源”列表。详情加载阶段自动展开每条分享资源，并汇总成普通站点同样的：

- 线路按钮：`baidu（N 集）`、`quark（N 集）`、`uc（N 集）`；
- 当前线路的 TMDB 剧集卡片；
- 点击换线路和换集走现有标准播放流程。

界面显示线路名与播放请求的原始 `flag` 分离：例如界面显示 `quark`，Android 网关播放请求仍发送它要求的原始 `丫仙女`。

## 数据归一化

`SiteService.folderDetail` 执行：

1. `t=<folder vod_id>` 获取分享资源；
2. 逐个用 `ids=<分享链>` 获取真实 `vod_play_from` / `vod_play_url`；
3. 把每个资源转换成 `VodPlayLine`，线路显示名使用资源提供商名称；
4. 在 `Vod.extra[bridge_playback_flags]` 保存“显示名 → 原始 flag”；
5. 保留父条目的 `vod_id` / `vod_name`，因此 TMDB、收藏和历史仍绑定作品，而不是 `atvp_resume:` 句柄。

部分资源失败不会阻挡其他线路；全部资源失败时显示详情错误，不伪装成成功的空目录。
